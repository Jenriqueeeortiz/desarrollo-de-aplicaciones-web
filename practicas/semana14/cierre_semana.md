 Cierre de la práctica — Semana 14

 1. Introducción

En esta práctica realicé pruebas de integración y regresión al sistema de citas para el salón de belleza, con la finalidad de comprobar que sus diferentes módulos funcionaran correctamente en conjunto.

 2. Actividades realizadas

- Se identificaron los módulos principales del sistema.
- Se elaboró un plan de pruebas de integración.
- Se revisó el funcionamiento de la autenticación y los permisos por roles.
- Se comprobó el registro, consulta, edición y eliminación de citas.
- Se verificó la búsqueda mediante Fetch API y los filtros avanzados.
- Se realizaron pruebas de regresión para comprobar las funciones anteriores.
- Se documentaron los resultados obtenidos.

 3. Errores encontrados

Durante las pruebas no se identificaron errores que impidieran el funcionamiento general del sistema. Por lo tanto, no fue necesario realizar modificaciones adicionales al código.

 4. Resultado final

El sistema mantuvo el funcionamiento esperado durante las pruebas realizadas. Los módulos principales trabajaron correctamente y las funciones implementadas en las prácticas anteriores continuaron disponibles.

 5. Conclusión

Con esta práctica pude comprobar la importancia de realizar pruebas de integración y regresión antes de entregar un proyecto. También pude revisar que las diferentes partes del sistema trabajaran correctamente y que las modificaciones realizadas no afectaran las funcionalidades existentes.

La práctica permitió dejar el sistema preparado para su presentación y entrega final.
